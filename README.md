Client Lead Management System (Mini CRM)

A full stack web application developed to manage client leads efficiently using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

This project allows users to add, view, and delete client leads through a modern and responsive dashboard interface. It helps in organizing client information such as name, email, lead source, and notes in a structured way.

Features
Add new client leads
View all leads dynamically
Delete leads
Responsive and professional dashboard UI
MongoDB database integration
REST API functionality
Frontend and backend connectivity

How to Run the Project
Clone the repository
Open the project in VS Code
Open terminal and move to backend folder:
cd backend
Install dependencies:
npm install
Start the server:
node server.js
Open frontend/index.html in browser
Purpose of the Project

The purpose of this project is to gain practical experience in full stack web development by building a real-world CRM application with frontend, backend, APIs, and database integration.
